## 사용자 시나리오 및 테스트 *(필수)*

### 사용자 스토리 1 - 신뢰할 수 있는 도서 검색 복구 (우선순위: P1)

로그인한 사용자는 기존 도서 검색 화면에서 한국 도서를 검색하고, 표지와 핵심 서지정보가
정리된 결과를 받아 원하는 판본을 찾을 수 있다.

**우선순위가 높은 이유**: 현재 기본 검색 경로가 중단된 외부 서비스에 의존하므로 검색이
복구되지 않으면 책 선택과 이후 Reading 흐름 전체가 시작될 수 없다.

**독립 테스트**: 실제 운영 후보인 도서 정보 출처를 사용해 제목 또는 저자로 검색하고,
정상 결과, 빈 결과, 일시적 실패와 응답 지연이 기존 검색 화면의 서로 다른 상태로
표시되는지 확인한다.

**인수 시나리오**:

1. **Given** 로그인한 사용자가 도서 검색 화면에 있고, **When** 결과가 있는 유효한
   검색어로 검색하면, **Then** 표지, 제목, 저자, 출판사와 출간연도를 포함한 정규화된
   결과가 표시된다.
2. **Given** 검색 조건과 일치하는 책이 없고, **When** 검색이 정상적으로 끝나면,
   **Then** 오류가 아닌 빈 결과 안내와 검색어를 바꿀 수 있는 행동이 표시된다.
3. **Given** 도서 정보 출처가 요청을 처리하지 못하거나 정해진 시간 안에 응답하지 않고,
   **When** 검색이 끝나면, **Then** 내부 상세를 노출하지 않는 오류 안내와 다시 시도할
   수 있는 행동이 표시된다.
4. **Given** 같은 도서의 정보에 ISBN10과 ISBN13이 함께 포함되어 있고, **When** 검색
   결과가 표시되면, **Then** 해당 판본을 식별할 ISBN13이 일관된 13자리 값으로 준비된다.

---

### 사용자 스토리 2 - 검색 결과에서 책 선택 및 등록 (우선순위: P1)

로그인한 사용자는 검색 결과에서 원하는 판본을 선택해 AfterMuse가 이후 독서 경험에
사용할 로컬 Book으로 확정할 수 있다.

**우선순위가 높은 이유**: 검색 결과를 선택해도 로컬 Book으로 이어지지 않으면 다음 단계인
Reading 생성의 안정적인 기준을 만들 수 없다.

**독립 테스트**: 아직 등록되지 않은 유효한 ISBN13의 검색 결과를 선택하고, 선택한
서지정보와 일치하는 Book 한 건이 등록되어 선택 완료 결과로 반환되는지 확인한다.

**인수 시나리오**:

1. **Given** 로컬에 없는 ISBN13을 가진 검색 결과가 있고, **When** 사용자가 해당 결과를
   선택하면, **Then** 검색 결과의 제목과 제공된 서지정보를 가진 Book 한 건이 등록되고
   그 Book이 선택 결과로 반환된다.
2. **Given** 제목과 ISBN13은 있지만 일부 선택 서지정보가 없는 검색 결과가 있고,
   **When** 사용자가 선택하면, **Then** 누락된 내용을 추측하지 않고 Book 등록이
   완료된다.
3. **Given** 사용자가 선택할 검색 결과가 서버에 임시 보관되어 있고, **When** 화면에서
   받은 후보 식별자로 선택하면, **Then** 화면이 다시 제출한 서지정보가 아니라 보관된
   검증 결과로 Book이 등록된다.

---

### 사용자 스토리 3 - 같은 판본의 중복 등록 방지 (우선순위: P2)

로그인한 사용자가 이미 등록된 판본을 다시 선택해도 시스템은 기존 Book을 재사용하여
도서 기록이 중복되거나 분산되지 않게 한다.

**우선순위가 높은 이유**: 같은 판본의 중복 Book은 향후 Reading과 Book Knowledge를
서로 다른 도서에 연결해 데이터 일관성을 훼손한다.

**독립 테스트**: 같은 ISBN13의 검색 결과를 순차 또는 동시에 여러 번 선택하고, 모든
성공 결과가 동일한 기존 Book을 가리키며 최종 Book 수가 한 건인지 확인한다.

**인수 시나리오**:

1. **Given** 선택한 ISBN13의 Book이 이미 등록되어 있고, **When** 사용자가 같은 판본을
   다시 선택하면, **Then** 새 Book을 만들지 않고 기존 Book을 선택 결과로 반환한다.
2. **Given** 같은 ISBN13에 대한 선택 요청이 거의 동시에 처리되고, **When** 모든 요청이
   완료되면, **Then** 해당 ISBN13의 Book은 정확히 한 건만 존재하고 성공한 요청은 그
   Book을 가리킨다.
3. **Given** 기존 Book과 같은 ISBN13이지만 다른 선택 서지정보를 가진 검색 결과가 있고,
   **When** 사용자가 선택하면, **Then** 기존 Book을 재사용하되 기존 서지정보를 암묵적으로
   덮어쓰지 않는다.

### 예외 상황

- 도서 정보 출처가 ISBN 값을 공백, 하이픈 또는 ISBN10과 함께 제공해도 유효한 ISBN13만
  판본 식별값으로 사용한다.
- ISBN13 후보가 없거나 ASCII 숫자 13자리로 정규화할 수 없는 도서는 검색 결과에서
  제외하며 식별값을 추측하지 않는다.
- 같은 제목이라도 ISBN13이 다르면 서로 다른 판본으로 보고 각각 별도 Book으로 등록할 수
  있다.
- 검색 결과의 제목이 비어 있으면 Book 등록에 필요한 최소 정보가 없으므로 선택을
  완료하지 않는다.
- 표지, 저자, 출판사, 출간일, 소개 또는 목차가 누락되어도 ISBN13과 제목이 유효하면
  등록할 수 있으며 누락된 값은 추측하지 않는다.
- 선택 처리 중 도서 정보 출처가 다시 실패하더라도 사용자가 본 유효한 검색 결과만으로
  등록 가능한 경우 선택을 불필요하게 막지 않는다.
- 선택 요청이 실패하면 부분적으로 생성된 중복 Book을 남기지 않고, 사용자가 같은 결과를
  다시 선택할 수 있어야 한다.
- 선택 후보가 만료되었거나 현재 사용자에게 속하지 않으면 Book을 생성하지 않고, 다시
  검색해야 한다는 안내를 제공한다.
- 검색 또는 선택 오류에는 자격 증명, 외부 응답 원문, 예외 이름이나 내부 진단 정보가
  노출되지 않아야 한다.
- 인증되지 않은 사용자는 검색 결과 선택으로 로컬 Book을 등록할 수 없다.

## 요구사항 *(필수)*

### 기능 요구사항

- **FR-001**: 시스템은 Core MVP의 한국 도서 검색을 지속적으로 사용할 수 있는 기본 도서
  정보 출처를 통해 제공해야 한다.
- **FR-002**: 시스템은 기존 검색 화면에서 정상 결과, 빈 결과, 검색 실패 및 응답 지연을
  서로 구분되는 상태로 제공해야 한다.
- **FR-003**: 시스템은 도서 정보 출처가 바뀌어도 검색어 입력, 결과 표시 정보, 결과 없음,
  오류 및 재시도에 관한 기존 사용자 경험을 유지해야 한다.
- **FR-004**: 각 정상 검색 결과는 제목을 표시하고, 제공된 경우 표지, 저자, 출판사,
  출간일 또는 출간연도, 소개, 목차와 ISBN13을 이후 선택에 사용할 수 있게 보존해야 한다.
- **FR-005**: 시스템은 외부 ISBN 표기에서 공백과 구분 문자를 제거하고, 여러 ISBN 후보가
  있으면 숫자 13자리 ISBN13을 판본 식별값으로 선택해야 한다.
- **FR-006**: 시스템은 유효한 ISBN13 또는 제목이 없는 외부 도서 항목을 검색 결과와
  선택 후보에서 제외해야 한다.
- **FR-007**: 로그인한 사용자는 유효한 ISBN13과 제목이 있는 검색 결과를 명시적으로
  선택할 수 있어야 한다.
- **FR-007A**: 시스템은 검증·정규화한 검색 결과를 현재 로그인한 사용자의 선택 후보로
  임시 보관하고 각 후보에 선택용 식별자를 부여해야 한다.
- **FR-007B**: 시스템은 선택 요청에서 후보 식별자만 신뢰하고, 화면이 별도로 제출한
  ISBN13 또는 서지정보를 Book 등록값으로 사용해서는 안 된다.
- **FR-007C**: 시스템은 선택 후보가 만료되었거나 현재 사용자와 일치하지 않으면 선택을
  거부하고 다시 검색할 수 있는 안내를 제공해야 한다.
- **FR-008**: 시스템은 선택한 ISBN13의 Book이 없으면 검색 결과에서 제공된 서지정보로
  Book 한 건을 등록해야 한다.
- **FR-009**: 시스템은 선택한 ISBN13의 Book이 이미 있으면 새 Book을 생성하지 않고 기존
  Book을 재사용해야 한다.
- **FR-010**: 기존 Book을 재사용하는 선택은 검색 결과의 값으로 기존 서지정보를
  암묵적으로 덮어써서는 안 된다.
- **FR-011**: 시스템은 동일 ISBN13의 순차 및 동시 선택에서도 최종 Book을 최대 한 건만
  유지해야 한다.
- **FR-012**: 시스템은 만료·변조·소유권 불일치 등 유효하지 않은 선택 후보를 거부하고
  재검색 안내를 제공해야 한다.
- **FR-013**: 시스템은 선택 서지정보가 누락된 경우 내용을 추측하지 않고 빈 값 또는 미상
  상태로 보존해야 한다.
- **FR-014**: 시스템은 검색 및 선택 실패 안내에 자격 증명, 외부 응답 원문, 예외 이름과
  내부 진단 정보를 노출해서는 안 된다.
- **FR-015**: 시스템은 선택 실패 시 불완전하거나 중복된 Book을 남기지 않고 같은 결과를
  안전하게 다시 선택할 수 있게 해야 한다.
- **FR-016**: 시스템은 인증되지 않은 사용자의 검색 결과 선택 및 Book 등록 요청을
  허용해서는 안 된다.
- **FR-017**: 이번 기능은 Book 선택 완료까지만 책임지며 Reading 생성, Book Knowledge 준비,
  독서노트 시작 및 기존 Book의 서지정보 갱신 정책을 포함하지 않아야 한다.

### 핵심 엔터티 *(기능에 데이터가 포함되는 경우 작성)*

- **도서 검색 결과**: 외부 도서 정보 출처에서 얻어 사용자가 판본을 식별하고 선택하는
  후보이다. 제목과 원본 ISBN 표기를 포함하며, 표지, 저자, 출판사, 출간일, 소개와 목차가
  선택적으로 존재한다. 영속적인 사용자 기록은 아니다.
- **도서 선택 후보**: 검증·정규화된 검색 결과를 현재 로그인한 사용자와 선택용 식별자에
  연결해 제한된 기간 동안 보관한 값이다. 만료되거나 다른 사용자의 후보는 Book 등록에
  사용할 수 없다.
- **Book**: AfterMuse가 Reading 등 후속 흐름에서 사용하는 출판 도서이다. ISBN13으로
  판본을 구분하며 제목은 필수이고, 같은 ISBN13에는 최대 한 건만 존재한다.
- **도서 선택 결과**: 사용자가 고른 검색 결과와 로컬 Book을 연결한 처리 결과이다. 새로
  등록한 Book과 기존에 재사용한 Book을 동일한 후속 계약으로 제공한다.

## 성공 기준 *(필수)*

### 측정 가능한 결과

- **SC-001**: 실제 Kakao key를 사용하는 명시적 live smoke에서 대표 한국 도서 검색어가
  유효한 ISBN13과 제목을 가진 결과를 1건 이상 반환한다.
- **SC-002**: 정상 결과, 빈 결과, 검색 실패 및 응답 지연 인수 시나리오의 상태 판별이
  100% 정확하고 기존 검색 사용자 흐름의 회귀가 0건이다.
- **SC-003**: ISBN10과 ISBN13이 함께 있거나 구분 문자가 포함된 대표 ISBN 표기 사례에서
  유효한 ISBN13 식별 결과의 정확도가 100%이다.
- **SC-004**: 유효한 ISBN13과 제목을 가진 신규 검색 결과 선택 인수 테스트에서 Book 등록
  성공률이 100%이고 제공된 서지정보의 손실 또는 임의 보완이 0건이다.
- **SC-005**: 같은 ISBN13을 순차 및 동시에 반복 선택하는 모든 인수 테스트에서 중복 Book
  생성이 0건이고 최종 Book 수는 항상 한 건이다.
- **SC-006**: 이미 등록된 ISBN13을 다시 선택하는 모든 인수 테스트에서 기존 Book 재사용률이
  100%이고 기존 서지정보의 의도하지 않은 변경이 0건이다.
- **SC-007**: 유효한 ISBN13이 없는 결과, 검색 실패 및 선택 실패의 모든 인수 테스트에서
  내부 진단 정보 노출과 불완전한 Book 생성이 각각 0건이다.
- **SC-007A**: 화면에서 ISBN13과 서지정보를 변경하거나 다른 사용자·만료된 후보 식별자를
  제출하는 모든 인수 테스트에서 변조된 Book 생성이 0건이다.
- **SC-008**: 1280px Desktop과 375px Mobile에서 키보드만 사용한 검색 시작부터 판본 선택
  완료까지의 흐름을 각각 2회 연속 2분 이내에 완료한다.

## 가정

  검색 화면과 Normal/Loading/Empty/Error 상태는 완료되어 있으며 이번 기능은 그 사용자
  계약을 유지한다.
- Core MVP의 한국 도서 정보 출처는 승인된 제품 결정에 따라 Kakao 도서 검색 API이며,
  알라딘 OpenAPI는 운영 후보에서 제외된다.
- 외부 도서 정보 출처의 유효한 접근 권한과 실제 운영 조건 확인은 검색 복구 완료를
  검증하기 위한 선행 환경 조건이다.
- Book의 필수값과 중복 기준은 기존 도메인 계약대로 구분 기호 없는 숫자 13자리 ISBN13과
  비어 있지 않은 제목이다.
- 같은 작품이어도 ISBN13이 다른 판본은 별도 Book으로 취급하며 Work와 Edition을 별도
  엔터티로 모델링하지 않는다.
- 검색 결과 선택은 사용자가 확인한 결과의 서지정보만 사용하며, 선택 시 추가적인 고비용
  정보 수집이나 Book Knowledge 준비를 시작하지 않는다.
- 기존 Book과 새 검색 결과의 서지정보가 다를 때 이번 기능은 기존 값을 유지한다. 서지정보
  병합, 최신화와 출처 우선순위는 별도 정책이 필요한 후속 범위이다.
- Book 선택 이후의 Book Detail 또는 Reading 화면 이동은 후속 기능이 결정한다. 이번
  기능은 후속 흐름이 재사용할 수 있는 선택된 Book을 반환하는 데까지를 완료로 본다.
