# 기능 사양: Book 기본 모델

**기능 브랜치**: `feature/day-02-auth-book-search`

**생성일**: 2026-09-02

**상태**: 초안

**입력**: 사용자 설명: "IMP-020 — ISBN13 중심의 Book 저장/조회 모델을 구현하고 제목, 저자 표시, 출판사, 출간일, 표지, 소개, 목차를 저장하며 ISBN 중복 방지 테스트를 통과한다. 선행 작업은 IMP-002이다."

## 사용자 시나리오 및 테스트 *(필수)*

### 사용자 스토리 1 - 도서 서지정보 저장 및 조회 (우선순위: P1)

도서 정보를 사용하는 후속 기능은 ISBN13과 제목을 포함한 Book을 등록하고, 나중에 같은 Book의 전체 서지정보를 손실 없이 조회할 수 있다.

**우선순위가 높은 이유**: 저장과 조회는 도서 선택, Reading 생성, Book Knowledge 연결이 공통으로 의존하는 최소 기반이다.

**독립 테스트**: 유효한 ISBN13과 모든 지원 서지정보로 Book 하나를 저장한 뒤 다시 조회하여 입력한 값이 모두 동일한지 확인할 수 있다.

**인수 시나리오**:

1. **Given** 유효한 ISBN13, 제목, 저자 표시, 출판사, 출간일, 표지 위치, 소개, 목차가 준비되어 있고, **When** Book을 저장한 뒤 ISBN13으로 조회하면, **Then** 저장한 Book 한 건과 모든 서지정보가 원래 값 그대로 반환된다.
2. **Given** 여러 Book이 서로 다른 ISBN13으로 저장되어 있고, **When** 특정 ISBN13을 조회하면, **Then** 해당 ISBN13의 Book만 정확히 반환된다.
3. **Given** 저장된 Book과 일치하지 않는 ISBN13이 있고, **When** 해당 ISBN13을 조회하면, **Then** Book이 없다는 결과가 명확하게 반환된다.

---

### 사용자 스토리 2 - 동일 ISBN 중복 방지 (우선순위: P1)

도서 정보를 사용하는 후속 기능은 이미 등록된 ISBN13으로 두 번째 Book을 만들 수 없으며, 하나의 ISBN13이 항상 하나의 Book을 가리킨다고 신뢰할 수 있다.

**우선순위가 높은 이유**: 중복 Book은 Reading과 Book Knowledge를 서로 다른 레코드로 분산시켜 핵심 제품 흐름의 데이터 일관성을 훼손한다.

**독립 테스트**: 동일한 ISBN13으로 Book을 두 번 저장하려고 시도하여 두 번째 시도가 거부되고 최초 Book 한 건만 남는지 확인할 수 있다.

**인수 시나리오**:

1. **Given** 특정 ISBN13의 Book이 이미 저장되어 있고, **When** 같은 ISBN13으로 다른 Book을 새로 저장하려 하면, **Then** 중복 저장은 거부되고 해당 ISBN13의 Book은 정확히 한 건만 유지된다.
2. **Given** 동일한 ISBN13을 가진 두 저장 요청이 거의 동시에 처리되고, **When** 두 요청이 완료되면, **Then** 최종적으로 해당 ISBN13의 Book은 한 건만 존재한다.
3. **Given** 중복 저장이 거부되기 전 최초 Book의 서지정보가 저장되어 있고, **When** 중복 시도 이후 기존 Book을 조회하면, **Then** 최초 Book의 서지정보는 중복 요청의 값으로 변경되지 않는다.

---

### 사용자 스토리 3 - 불완전한 선택 서지정보 보존 (우선순위: P2)

도서 정보를 사용하는 후속 기능은 외부 자료에 일부 선택 서지정보가 없더라도 ISBN13과 제목만으로 Book을 저장하고 다시 조회할 수 있다.

**우선순위가 높은 이유**: 실제 도서 자료는 출간일, 표지, 소개 또는 목차가 누락될 수 있으므로, 불완전한 자료도 핵심 도서 흐름을 막지 않아야 한다.

**독립 테스트**: ISBN13과 제목만 제공하고 Book을 저장한 뒤, 선택 서지정보가 미상 또는 빈 값으로 일관되게 조회되는지 확인할 수 있다.

**인수 시나리오**:

1. **Given** 유효한 ISBN13과 제목만 있고 선택 서지정보는 제공되지 않았으며, **When** Book을 저장하고 조회하면, **Then** 저장은 성공하고 선택 서지정보는 추측된 내용 없이 미상 또는 빈 값으로 반환된다.
2. **Given** 목차가 제공되지 않은 Book이 있고, **When** 해당 Book을 조회하면, **Then** 시스템은 책 내용을 추론해 목차를 채우지 않고 빈 목차를 반환한다.

### 예외 상황

- ISBN13이 없거나 ASCII 숫자 13자리가 아니면 어떤 Book 저장 경로도 허용하지 않는다.
- 제목이 없거나 빈 값이면 Book 저장을 허용하지 않는다.
- 출간일을 알 수 없으면 미상으로 보존하며 임의의 날짜를 생성하지 않는다.
- 저자 표시, 출판사, 표지 위치, 소개 또는 목차가 제공되지 않으면 빈 값으로 보존한다.
- 표지 위치가 제공되더라도 이번 기능은 해당 위치의 원격 자원 존재 여부를 보장하지 않는다.
- 같은 책의 다른 판본이 서로 다른 ISBN13을 가지면 각각 별도 Book으로 저장할 수 있다.

## 요구사항 *(필수)*

### 기능 요구사항

- **FR-001**: 시스템은 Book을 ISBN13으로 식별해야 한다.
- **FR-002**: 시스템은 모든 Book 저장 경로에서 ISBN13이 ASCII 숫자 13자리인지 검증하고, 그렇지 않으면 저장을 거부해야 한다.
- **FR-003**: 시스템은 모든 Book 저장 경로에서 ISBN13 또는 제목이 비어 있으면 저장을 거부해야 한다.
- **FR-004**: 시스템은 Book의 제목, 저자 표시, 출판사, 출간일, 표지 위치, 소개 및 목차를 저장하고 조회할 수 있어야 한다.
- **FR-005**: 시스템은 출간일을 알 수 없는 상태와 알려진 날짜를 구분해 보존해야 한다.
- **FR-006**: 시스템은 제공되지 않은 저자 표시, 출판사, 표지 위치, 소개 및 목차를 빈 값으로 보존해야 하며 내용을 추측해 채워서는 안 된다.
- **FR-007**: 시스템은 주어진 ISBN13과 일치하는 Book을 최대 한 건 반환해야 한다.
- **FR-008**: 시스템은 존재하지 않는 ISBN13 조회를 기존 Book과 구분되는 '없음' 결과로 반환해야 한다.
- **FR-009**: 시스템은 이미 저장된 ISBN13으로 새로운 Book을 저장하는 모든 시도를 거부해야 한다.
- **FR-010**: 시스템은 중복 저장 시도가 거부되어도 기존 Book의 서지정보를 변경해서는 안 된다.
- **FR-011**: 시스템은 서로 다른 ISBN13을 가진 Book을 서로 독립된 도서로 저장할 수 있어야 한다.
- **FR-012**: Book 저장 및 조회 기능은 완료된 데이터 영속화 개발 환경 구성(IMP-002)을 선행 조건으로 사용해야 한다.

### 핵심 엔터티 *(기능에 데이터가 포함되는 경우 작성)*

- **Book**: MVP에서 하나의 ISBN13으로 구분되는 출판 도서를 나타낸다. 필수 속성은 ASCII 숫자 13자리 ISBN13과 제목이며, 선택 속성은 저자 표시, 출판사, 출간일, 표지 위치, 소개, 목차이다. 하나의 ISBN13에는 최대 하나의 Book만 존재한다.

## 성공 기준 *(필수)*

### 측정 가능한 결과

- **SC-001**: 모든 필드를 채운 Book 저장·조회 인수 테스트에서 ISBN13과 7개 서지정보가 100% 동일하게 보존된다.
- **SC-002**: ISBN13과 제목만 있는 Book 저장·조회 인수 테스트에서 선택 정보 누락으로 인한 실패가 0건이며, 누락 정보에 추측된 값이 추가되지 않는다.
- **SC-003**: 동일 ISBN13에 대한 순차 및 동시 중복 저장 인수 테스트에서 중복 Book 생성이 0건이고 최종 Book 수는 항상 1건이다.
- **SC-004**: 유효한 서로 다른 ISBN13 100건을 저장하고 각각 조회했을 때 잘못된 Book 반환 또는 필드 손실이 0건이다.
- **SC-005**: 저장된 ISBN13과 존재하지 않는 ISBN13의 단건 조회 중 95% 이상이 1초 이내에 성공 또는 '없음' 결과를 반환한다.
- **SC-006**: IMP-020의 저장, 조회, 필수값 검증 및 ISBN 중복 방지 인수 시나리오가 모두 통과한다.

## 가정

- 선행 작업 IMP-002의 데이터 저장소 연결, 개발 환경변수 및 빈 저장소 초기화 흐름은 완료되어 있다.
- ISBN13은 구분 기호가 없는 ASCII 숫자 13자리의 정규화된 값으로 입력되며, 이번 기능은 체크 디지트 유효성까지 판정하지 않는다.
- 제목은 필수이며, 저자 표시, 출판사, 표지 위치, 소개, 목차는 제공되지 않으면 빈 값으로 보존한다. 출간일은 제공되지 않으면 미상으로 보존한다.
- 저자는 개별 인물 엔터티로 분리하지 않고 도서 자료가 제공한 표시 문자열로 취급한다.
- 표지는 이미지 파일 자체가 아니라 표지를 가리키는 위치 정보로 보존한다.
- Work와 Edition의 별도 모델, 원본 Metadata 보관, 외부 Provider 식별자, Metadata 병합·갱신 정책은 이번 기능의 범위가 아니다.
- Metadata Provider 연동(IMP-021), 검색 결과 정규화(IMP-022), 검색 화면(IMP-023), 검색 결과를 로컬 Book으로 등록하는 흐름(IMP-024)은 후속 작업이다.
- Book을 최종 사용자에게 직접 노출하는 화면과 사용자별 접근 권한은 이번 기능의 범위가 아니다.
