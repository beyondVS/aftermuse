**기능 브랜치**: `feature/day-02-auth-book-search`

**상태**: 초안

**입력**: 사용자 설명: "IMP-022 — 선행 작업 IMP-020과 IMP-021을 기반으로 검색어를 Provider에 전달하고 표지, 저자, 출판사, 출간연도 중심으로 결과를 정규화하며 정상 검색, 결과 없음, Provider 실패를 구분한다."

## Clarifications

### Session 2026-09-03

- Q: 검색 Service는 출간 정보를 어떤 형태로 후속 흐름에 제공해야 합니까? → A: 전체 출간일을 보존하고 후속 화면에서 연도만 표시한다.

## 사용자 시나리오 및 테스트 *(필수)*

### 사용자 스토리 1 - 정규화된 도서 검색 결과 제공 (우선순위: P1)

사용자는 입력한 검색어와 일치하는 도서를 찾고, 후속 검색 화면이 특정 Metadata 제공자의
형식에 의존하지 않고 ISBN13, 제목, 표지, 저자 표시, 출판사와 출간일을 사용할 수 있는
일관된 검색 결과를 받는다.

**우선순위가 높은 이유**: 검색 결과가 일관된 형태로 제공되어야 사용자가 판본을 구분하고
다음 단계에서 원하는 책을 선택할 수 있다.

**독립 테스트**: 앞뒤 공백이 있는 검색어와 준비된 도서 결과를 사용해 검색을 수행하고,
정리된 검색어가 전달되며 도서의 순서와 식별자·서지정보가 보존된 성공 결과인지 확인한다.

**인수 시나리오**:

1. **Given** 앞뒤에 공백이 있는 유효한 검색어와 한 건 이상의 도서 결과가 준비되어 있고, **When** 도서를 검색하면, **Then** 공백이 제거된 검색어로 검색되고 성공 상태와 도서 결과가 반환된다.
2. **Given** 여러 도서 결과가 제공되고, **When** 결과를 정규화하면, **Then** 제공된 순서와 각 도서의 ISBN13, 제목, 표지, 저자 표시, 출판사, 출간일 및 나머지 서지정보가 손실 없이 유지된다.

---

### 사용자 스토리 2 - 빈 결과와 검색 실패 구분 (우선순위: P1)

사용자는 검색 결과가 없는 경우와 Metadata 제공자가 요청을 처리하지 못한 경우를 서로
다른 상태로 전달받아, 후속 검색 화면에서 적절한 안내를 받을 수 있다.

**우선순위가 높은 이유**: 제공자 장애를 검색 결과 없음으로 오인하면 사용자는 실제로
존재하는 책을 찾을 수 없다고 판단할 수 있다.

**독립 테스트**: 정상 빈 응답과 설정 오류, timeout, 통신 오류 및 해석 불가능한 응답을
각각 재현해 빈 결과와 오류 결과가 서로 구분되고 외부 오류 상세가 노출되지 않는지 확인한다.

**인수 시나리오**:

1. **Given** 유효한 검색어에 일치하는 도서가 없고, **When** 검색을 완료하면, **Then** 실패가 아닌 빈 결과 상태가 반환된다.
2. **Given** Metadata 제공자의 설정, timeout, 통신 또는 응답 해석 오류가 발생하고, **When** 검색을 완료하면, **Then** 빈 결과와 구분되는 오류 상태가 반환된다.
3. **Given** Metadata 제공자가 민감하거나 내부적인 오류 상세를 제공하고, **When** 오류 결과를 반환하면, **Then** 해당 상세는 검색 결과에 포함되지 않는다.

---

### 사용자 스토리 3 - 의미 없는 검색 방지 (우선순위: P2)

사용자가 공백만 입력하면 외부 검색을 실행하지 않고 빈 결과를 받아 불필요한 요청과
혼란을 피한다.

**우선순위가 높은 이유**: 의미 없는 입력을 외부로 전달하지 않으면 자원을 절약하고 검색
상태를 예측 가능하게 유지할 수 있다.

**독립 테스트**: 공백으로만 구성된 검색어를 사용해 검색하고, 외부 검색 요청이 발생하지
않으며 빈 결과 상태와 빈 도서 목록이 반환되는지 확인한다.

**인수 시나리오**:

1. **Given** 검색어가 비어 있거나 공백으로만 구성되어 있고, **When** 검색을 요청하면, **Then** 외부 검색 없이 빈 결과 상태와 빈 도서 목록이 반환된다.

### 예외 상황

- 검색어 양끝의 공백은 제거하지만 검색어 내부의 공백과 문자는 원래 의미대로 보존한다.
- 정상 응답의 도서가 0건이면 오류가 아니라 빈 결과로 처리한다.
- 성공 상태에는 한 건 이상의 도서가 있어야 하고, 빈 결과와 오류 상태에는 도서가 없어야 한다.
- Metadata 제공자의 설정 오류, timeout, 통신 오류 또는 응답 해석 오류는 모두 후속 소비자가
  특정 제공자 오류에 의존하지 않는 하나의 검색 오류 상태로 격리한다.
- 검색 결과의 선택 서지정보가 비어 있어도 해당 결과를 임의로 보완하거나 검색 전체를
  실패시키지 않는다.
- 같은 검색어가 반복되어도 이번 기능은 결과를 저장하거나 캐시하지 않는다.

## 요구사항 *(필수)*

### 기능 요구사항

- **FR-001**: 시스템은 검색어의 양끝 공백을 제거한 뒤 Metadata 검색을 수행해야 한다.
- **FR-002**: 시스템은 검색어 내부의 문자와 공백을 변경하지 않고 원래 의미를 유지해야 한다.
- **FR-003**: 시스템은 공백 제거 후 검색어가 비어 있으면 외부 검색을 수행하지 않아야 한다.
- **FR-004**: 시스템은 유효한 검색어마다 Metadata 검색을 한 번 수행해야 한다.
- **FR-005**: 시스템은 한 건 이상의 도서가 반환되면 성공 상태로 분류해야 한다.
- **FR-006**: 시스템은 정상적으로 도서가 반환되지 않으면 빈 결과 상태로 분류해야 한다.
- **FR-007**: 시스템은 Metadata 제공자의 설정 오류, timeout, 통신 오류 및 응답 해석 오류를
  빈 결과와 구분되는 검색 오류 상태로 분류해야 한다.
- **FR-008**: 성공, 빈 결과 및 오류 상태는 서로 중복되지 않아야 한다.
- **FR-009**: 성공 결과는 Metadata 제공자가 반환한 도서 순서를 보존해야 한다.
- **FR-010**: 시스템은 각 결과의 ISBN13, 제목, 표지, 저자 표시, 출판사, 전체 출간일, 소개,
  목차 및 원본 도서 위치를 제공된 값 그대로 보존해야 한다.
- **FR-011**: 시스템은 선택 서지정보의 빈 값을 추측하거나 임의로 보완해서는 안 된다.
- **FR-012**: 오류 결과에는 Metadata 제공자의 자격 증명, 원본 오류 본문 또는 내부 오류
  상세가 포함되어서는 안 된다.
- **FR-013**: 후속 검색 흐름은 특정 Metadata 제공자의 오류 유형이나 응답 형식에 의존하지
  않고 검색 상태와 정규화된 도서 결과만 사용할 수 있어야 한다.
- **FR-014**: 시스템은 검색 과정에서 도서를 저장하거나 기존 도서 정보를 변경해서는 안 된다.
- **FR-015**: 시스템은 이번 기능에서 재시도, 검색 결과 캐시 또는 여러 Metadata 제공자 간
  결과 병합을 수행해서는 안 된다.
- **FR-016**: 정상, 빈 결과, 각 Provider 실패 및 공백 검색어의 자동 검증은 실제 외부
  서비스 호출 없이 수행할 수 있어야 한다.

### 핵심 엔터티

- **도서 검색 요청**: 사용자가 입력한 검색어와 공백 제거 후 실제 검색에 사용되는 검색어를
  나타낸다.
- **정규화된 도서 결과**: ISBN13과 제목을 필수로 가지며 표지, 저자 표시, 출판사, 전체
  출간일, 소개, 목차 및 원본 도서 위치를 선택 정보로 가진다.
- **도서 검색 결과**: 성공, 빈 결과 또는 오류 중 정확히 하나의 상태와 해당 상태에 맞는
  도서 목록을 가진다.

## 성공 기준 *(필수)*

### 측정 가능한 결과

- **SC-001**: 앞뒤 공백이 있는 검색어 검증의 100%에서 공백이 제거된 검색어가 정확히 한 번
  검색에 사용되고 내부 문자열은 변경되지 않는다.
- **SC-002**: 한 건 이상의 정상 결과 검증의 100%가 성공으로 분류되고 도서 순서와 제공된
  서지정보가 모두 보존된다.
- **SC-003**: 정상 빈 응답 검증의 100%가 오류가 아닌 빈 결과로 분류된다.
- **SC-004**: 설정 오류, timeout, 통신 오류 및 응답 해석 오류 검증의 100%가 빈 결과와
  구분되는 오류 상태로 분류된다.
- **SC-005**: 공백 검색어 검증에서 외부 검색 요청은 0건이며 빈 도서 목록이 반환된다.
- **SC-006**: 모든 결과 상태 검증에서 성공 상태의 빈 도서 목록과 빈 결과·오류 상태의
  비어 있지 않은 도서 목록은 각각 0건이다.
- **SC-007**: 오류 결과에서 자격 증명, 원본 오류 본문 또는 내부 오류 상세 노출은 0건이다.
- **SC-008**: 자동 검증 중 실제 외부 서비스 호출, 도서 생성, 기존 도서 변경 및 검색 결과
  캐시 생성은 모두 0건이다.

## 가정

- IMP-020의 ISBN13 중심 도서 모델과 IMP-021의 Provider 중립 Metadata 검색 계약이 완료되어
  있다.
- 검색어 길이와 허용 문자에 대한 사용자 입력 검증 및 화면 표시는 IMP-023에서 다룬다.
- Metadata 제공자가 반환하는 개별 도서의 필수값 검증과 선택값 정규화는 IMP-021의 책임이다.
- 이 기능은 검색 결과의 상태와 데이터를 후속 흐름에 전달하지만 검색 화면, 인증 및 사용자
  상호작용은 구현하지 않는다.
- 검색 Service는 전체 출간일을 보존하며, 출간연도 표시는 IMP-023의 검색 화면에서 해당
  출간일로부터 파생한다.
- 검색 결과에서 로컬 도서를 생성하거나 기존 도서를 재사용하는 흐름은 IMP-024에서 다룬다.
- Provider별 timeout과 통신 오류의 세부 차이는 진단용 경계 안에 남기고 후속 검색 화면에는
  하나의 안전한 오류 상태로 제공한다.
