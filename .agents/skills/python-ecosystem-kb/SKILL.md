# Python Ecosystem Knowledge Base Skill

본 스킬은 파이썬 및 Django 생태계 패키지를 추천하거나 탐색할 때 최신성과 검증 가능성을 높이기 위한 온디맨드(On-Demand) 레퍼런스 가이드입니다.

> [!IMPORTANT]
> **최신성 및 공식 출처 검증 1순칙 (PyPI & Web Search First)**
> - 로컬 카탈로그는 검증된 마이너/메이저 패키지 분류를 빠르게 참고하는 **초단축 1차 인덱스**일 뿐입니다.
> - 최종 추천 시에는 반드시 **PyPI(`pypi.org`), 공식 라이브러리 문서, 최신 웹 검색**을 통해 현재 유지보수 상태, 지원 파이썬/프레임워크 버전, 보안 공지, 라이선스를 확인하고 추천해야 합니다.
