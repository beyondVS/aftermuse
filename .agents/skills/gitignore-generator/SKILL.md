# Gitignore Generator Skill (gitignore.io 기반 .gitignore 생성 스킬)

본 스킬은 `gitignore.io` (Toptal Gitignore API)를 활용하여 프로젝트의 기술 스택(언어, 프레임워크, IDE, OS)에 맞는 맞춤형 `.gitignore` 파일을 생성하고 기존 파일과 원등성(Idempotency)을 보장하며 안전하게 병합하는 스킬입니다.

파이썬 등 외부 런타임에 의존하지 않고, Windows(PowerShell) 및 Linux/macOS(Bash) 네이티브 쉘 스크립트로 100% 동작합니다.

---

## ⚙️ 1. 실행 환경 및 Prerequisites

- **Windows**: PowerShell 5.1 이상
- **Linux / macOS / Git Bash**: Bash 및 `curl`
- **외부 런타임 의존성**: 0 (Python 미설치 환경에서도 100% 작동)

---

## 🔒 2. 절차적 통제 수칙 (Strict Execution Control)

1. **조회 작업 (자율 수행 가능)**:
   - 지원하는 템플릿 목록 조회(`-List` / `-l`) 및 키워드 조합 판단은 별도 승인 없이 수행할 수 있습니다.
2. **수정/생성 작업**:
   - 사용자가 `.gitignore` 생성 또는 수정을 직접 요청했고 Target 키워드와 출력 경로가 명확하면 그 요청을 실행 승인으로 봅니다.
   - 직접 요청하지 않은 변경이거나 대상·범위가 불명확하면 Target 키워드, 출력 경로, 백업 계획을 요약하고 실행 전에 확인합니다.

---

## 🚀 3. 사용법 및 OS별 런타임 분기 가이드

에이전트는 사용자의 OS 환경을 확인한 후 아래 명령어 중 적절한 스크립트를 선택하여 실행합니다.

### 1) Windows 환경 (PowerShell)
```powershell
# 기본 실행 (Python, VSCode, Windows 예시)
powershell -ExecutionPolicy Bypass -File .agents/skills/gitignore-generator/scripts/gitignore.ps1 -Targets "python,visualstudiocode,windows"

# 출력 파일 경로 지정
powershell -ExecutionPolicy Bypass -File .agents/skills/gitignore-generator/scripts/gitignore.ps1 -Targets "node,jetbrains" -Output ".gitignore"

# 지원 템플릿 목록 조회
powershell -ExecutionPolicy Bypass -File .agents/skills/gitignore-generator/scripts/gitignore.ps1 -List
```

### 2) Linux / macOS / Git Bash 환경 (Bash)
```bash
# 기본 실행
bash .agents/skills/gitignore-generator/scripts/gitignore.sh -t "python,visualstudiocode,windows"

# 출력 파일 경로 지정
bash .agents/skills/gitignore-generator/scripts/gitignore.sh -t "node,jetbrains" -o ".gitignore"

# 지원 템플릿 목록 조회
bash .agents/skills/gitignore-generator/scripts/gitignore.sh -l
```

## 💡 4. 별칭(Alias) 지원 목록

사용자 편의성을 위해 자주 쓰이는 단축 키워드는 정규 이름으로 자동 변환됩니다.

| 입력 키워드 (Alias) | 변환되는 정규 템플릿 이름 |
| :--- | :--- |
| `vscode` | `visualstudiocode` |
| `mac` | `macos` |
| `py` | `python` |
| `dotnet` | `dotnetcore` |
| `react` | `reactnative,node` |
| `jetbrains` | `jetbrains+all` |

---

## 🛡️ 5. 마커 기반 원등성(Idempotency) 병합 동작 방식

생성된 구역은 아래와 같이 마커 태그로 감싸져 기존 파일에 반영됩니다:

```gitignore
# >>> gitignore-generator managed section start >>>
# Generated by gitignore-generator on 2026-07-26 16:00:00
# Targets: python,visualstudiocode,windows

# ... (gitignore.io 내용) ...

# <<< gitignore-generator managed section end <<<
```

- **재실행 시 안전성**: 스크립트를 여러 번 재실행해도 구역이 중복 누적되지 않으며, 마커 구역 내부의 이전 내용만 **수술적으로 교체(Replace)**됩니다.
- **백업 생성**: 기존 `.gitignore`가 존재할 경우, 작업 실행 직전 `.gitignore.bak_YYYYMMDD_HHMMSS` 타임스탬프 백업 파일이 자동 생성됩니다.
- **인코딩 및 개행 보존**: 기존 파일은 인코딩과 주 개행 형식을 보존하고 마커 구역 밖의 내용을 유지합니다. 신규 파일은 BOM 없는 UTF-8과 POSIX LF(`\n`)를 사용하며, 기존 형식을 안전하게 보존할 수 없으면 파일을 변경하지 않고 오류를 보고합니다.
